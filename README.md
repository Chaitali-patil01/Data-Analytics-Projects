HR Data Analytics Dashboard | Power BI

Project Overview

An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee data and generate meaningful HR insights.

Tools & Technologies

Microsoft Power BI

Power Query

Data Visualization

DAX

Dashboard Features

Employee Headcount: Displays the total number of employees.

Average Salary: Shows the average employee salary.

Leave Balance: Displays the average leave balance.

Job Role Analysis: Shows employee distribution across different job roles.

Gender Distribution: Analyzes the percentage of male and female employees.

Age Distribution: Visualizes employee demographics by age.

Salary vs Qualification: Analyzes the relationship between employee qualifications and salaries.

Employee Growth: Shows cumulative employee growth over time.
